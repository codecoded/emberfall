# Emberfall — Legend of the Rune Knight

A 2D platform adventure in the spirit of *Leander* (Amiga, 1991), told twice:

| | Path | Stack |
|---|---|---|
| **Modern** | `/modern/` | three.js side-scroller in a low-poly 3D world; characters and props modelled, rigged and animated in Blender |
| **Classic** | `/pixel/` | Amiga-style pixel art on a 384×216 canvas, everything generated in code, no dependencies |

Find the Rune Stone in each realm, open the portal, trade gold with the wandering merchant for better
armour and blades, and face Malgrim the Ashen Sorcerer.

## Run

```sh
npm install
npm run dev        # http://localhost:5180  (landing page links to both versions)
npm run build      # static site in dist/
npm run deploy     # build and publish to GitHub Pages
```

Live at https://codecoded.github.io/emberfall/

## Controls

| | |
|---|---|
| Move | ← → / A D |
| Jump | Space / Z / K (hold for height), ↑ / W |
| Sword | X / J |
| Crouch, drop through planks | ↓ / S (+ jump) |
| Trade with the merchant | ↑ beside the stall |
| Pause · Mute · Fullscreen | P / Esc · M · F |

A gamepad works too (stick/d-pad, A to jump, X/B to attack).

On phones and tablets both versions show touch controls (thumb pad, JUMP, SWORD, pause) and scale to the
screen; landscape gives the widest view. `src/touch.js` is shared (copied to `pixel/src/touch.js`).

## Modern version layout

```
modern/index.html       page shell
src/main.js             renderer, bloom, fixed-step loop
src/game.js             player, enemies, boss, pickups, shop, camera, mode flow
src/levels.js           level DSL (ground segments + things placed on them) and the four levels
src/world.js            per-realm themes, terrain mesh, rolling backdrop, prop scatter, sky/liquid shaders, lights
src/actors.js           wrappers around the Blender models (animation mixing, hit flash)
src/fx.js               particles, sword-slash arc
src/audio.js            synthesised music sequencer + sound effects (WebAudio)
src/ui.js, style.css    HUD, title, shop and end screens
public/assets/*.glb     built by the Blender scripts below
```

### Rebuilding the 3D assets

All models are generated by Python scripts run headlessly in Blender (tested with 5.2):

```sh
npm run assets          # or: BLENDER=/path/to/blender sh tools/build-assets.sh
```

- `tools/blender/lib.py` — mesh builder (vertex-coloured primitives), armature and animation helpers, glTF export
- `tools/blender/humanoid.py` — hero, skeleton, sorcerer and merchant on one shared rig with 11 animations
- `tools/blender/creatures.py` — slime, bat, spitter plant
- `tools/blender/props.py` — trees, rocks, crystals, architecture, pickups, swords…

`viewer.html?m=props&cols=12&cell=2.6&norm=1` (dev server only) shows any GLB; for characters use
`viewer.html?m=hero&a=Idle,Run,Attack&cols=3`.

### Checks

```sh
node tools/check-levels.mjs    # conservative reachability: start → rune, portal, shrines, chests
```

In the browser console, `__game` exposes the running game (`__game.begin(2)` jumps to realm 3,
`__game.stats.coins = 200`, …).
